## MODIFIED Requirements

### Requirement: TOPIC-01 私人专题与成果保存

系统 SHALL 支持按关键词、领域或事件建立专题，自动匹配与手动加入报道；提供笔记新增、预览、编辑、删除，以及成果保存、改名和删除。移除的报道不被自动匹配重新加入，保存时保留生成正文、技能和来源快照。

#### Scenario: 建立与匹配
- **GIVEN** 用户有明确关注范围。
- **WHEN** 创建专题并加入新闻。
- **THEN** 自动匹配与手动加入的内容集中可读，未读数量及状态真实。

#### Scenario: 管理材料与笔记
- **GIVEN** 专题已有报道和 Markdown 笔记。
- **WHEN** 移除报道、预览修改笔记并保存或删除。
- **THEN** 修改持久，移除报道不会在刷新时回填；主动重新加入可以恢复。

#### Scenario: 保存与再生成
- **GIVEN** 编辑产生成功成果。
- **WHEN** 保存到当前专题，随后生成另一份并改名。
- **THEN** 默认选择当前专题并提供查看入口，每份保留生成时来源，正文不重复显示。

#### Scenario: 删除与权限
- **GIVEN** 对象属于本人、他人或不存在。
- **WHEN** 删除成果、笔记或专题。
- **THEN** 只删除本人选定对象及其关联分享，公共新闻和其他成果保留；越权及缺失统一返回不存在。

#### Scenario: 无效条件
- **GIVEN** 专题名称或关注范围缺失。
- **WHEN** 创建专题。
- **THEN** 字段附近说明错误，保留输入且不创建空对象。

#### Scenario: 并发部分更新
- **GIVEN** 同一账号在两个标签页分别修改专题名称与描述。
- **WHEN** 两个部分更新请求并发完成。
- **THEN** 两项修改都保留，未提交字段保持数据库当前值；他人更新仍返回不存在且不改变记录。
