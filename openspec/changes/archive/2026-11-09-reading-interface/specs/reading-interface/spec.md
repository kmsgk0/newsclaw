# Spec Delta

## Purpose

提供统一而自然的中文新闻阅读界面，使资讯、个人编辑、技能和专题具有清楚的操作路径。正文、生成结果和状态反馈在不同屏幕尺寸保持可读、可操作，页面表达围绕实际内容与功能。

## ADDED Requirements

### Requirement: UI-01 页面结构与导航

系统 SHALL 提供所有产品页面的清楚入口，以功能名称和实际内容组织页面，统一搜索范围、标题、控件和反馈。采用暖白背景、白色面板、深色正文和蓝色重点操作。保留必要说明、数字角标及功能入口，减少重复宣传文案。

#### Scenario: 页面导航
- **GIVEN** 用户使用资讯、编辑、技能、热点、专题、收藏、消息或设置。
- **WHEN** 切换页面、返回或刷新。
- **THEN** 入口与内容一致，当前分区可识别，URL保留应恢复的筛选与页签，404提供返回入口。

#### Scenario: 内容层级
- **GIVEN** 页面有长标题、中文和英文内容。
- **WHEN** 在桌面及手机阅读。
- **THEN** 标题、来源、正文和主要动作优先，辅助信息不挤占核心阅读空间，侧栏不使用选中竖条或扁椭圆浅蓝胶囊。

#### Scenario: 登录衔接
- **GIVEN** 游客打开私人页面或会话恢复完成。
- **WHEN** 登录后返回或刷新报道。
- **THEN** 回到原目标并显示当前账号的真实收藏及关注状态。

### Requirement: UI-02 Markdown 与来源呈现

系统 SHALL 在新闻、对话、日报、笔记、成果和分享中统一安全渲染 Markdown，保留文档结构并按阅读场景调整排版，引用编号链接到对应材料。

#### Scenario: 完整正文
- **GIVEN** 输入含多级标题、嵌套列表、表格、引用、代码、图片、任务列表和链接。
- **WHEN** 展示于正文或结果页面。
- **THEN** 层级、间距和行宽清楚，代码和表格可独立滚动，链接可操作，内容不被页面裁切。

#### Scenario: 引用与流式文本
- **GIVEN** 回答包含有效来源引用并持续输出。
- **WHEN** 阅读并打开引用或上翻历史。
- **THEN** 引用可直接追溯，流式内容不显示两份正文，不强行打断向上阅读。

#### Scenario: 回答与检索材料
- **GIVEN** 一次回答取得多篇材料，但正文或导图只引用其中一部分。
- **WHEN** 查看生成中的回答、完成后的回答或重新打开会话。
- **THEN** 默认展示实际引用的来源，其他检索材料折叠且可展开，来源编号与链接保持一致；自动滚动跟随回答正文而非来源列表，手动上翻后保持阅读位置。

#### Scenario: 外部内容
- **GIVEN** 新闻或模型文本包含 HTML 与危险链接。
- **WHEN** 渲染正文。
- **THEN** 不执行脚本或任意HTML，合法文字和安全链接仍可读。

### Requirement: UI-03 编辑工作区与表单操作

系统 SHALL 让当前材料、会话和输入区域清楚可见，桌面和手机均能完成主要操作。表单错误贴近字段，独立操作保留各自结果，失败保留有效输入。

#### Scenario: 输入与切换
- **GIVEN** 常见笔记本或手机尺寸下打开编辑。
- **WHEN** 新建、选择材料、输入、切换会话。
- **THEN** 输入框在工作区内可见，手机会话列表可收起，切换不会把旧回答写入新会话。

#### Scenario: 保存与失败
- **GIVEN** 用户填写设置、专题、笔记或技能。
- **WHEN** 提交成功或发生错误。
- **THEN** 显示对应结果与下一步，避免重复提交，失败保留填写内容且字段错误可定位。

#### Scenario: 账号输入与服务错误
- **GIVEN** 登录、注册或修改密码时存在必填、长度、格式或认证问题。
- **WHEN** 失焦、提交、修正输入或切换表单。
- **THEN** 显示具体中文原因，字段问题定位到对应输入，保留有效内容，旧错误不带入其他表单；普通输入与认证错误不显示排查编号，服务故障可展开请求标识。

#### Scenario: 异步结果
- **GIVEN** 后台任务等待、成功空结果、失败或生成内容。
- **WHEN** 查看状态。
- **THEN** 说明真实对象和结果，失败有合适重试入口，已有内容继续可读。

### Requirement: UI-04 响应式与实际行为验证

系统 SHALL 在390、768和1440像素宽度以及常见笔记本高度下保持可用布局，主要控件支持键盘及可见焦点，弹窗和图形提供可访问替代。

#### Scenario: 窄屏与长内容
- **GIVEN** 页面含长新闻、表格、表单和图谱。
- **WHEN** 切换屏幕尺寸并实际操作。
- **THEN** 页面不横向溢出，重要控件不被遮挡，图谱列表包含同样关系与来源。

#### Scenario: 键盘与弹窗
- **GIVEN** 用户通过键盘导航。
- **WHEN** 打开、操作并关闭对话框。
- **THEN** 标签对应输入，焦点可见且返回合理位置，主要操作不依赖悬停。

#### Scenario: 完整阅读过程
- **GIVEN** 真实数据和隔离场景均已准备。
- **WHEN** 走完阅读、问答、技能、保存、分享和回看。
- **THEN** 确认内容、操作结果及刷新持久性，截图与自动化检查共同反映实际完成情况。
