# Design

## Context

后端已提供新闻、个人编辑、技能和专题 API。本变更接入这些能力，提供统一的中文新闻阅读界面及清楚的操作路径。正文、生成结果和状态反馈在不同屏幕尺寸保持可读、可操作，页面表达围绕实际内容与功能。

## Goals / Non-Goals

**Goals:** 保留完整阅读功能，提供明确操作、可信来源及连续使用体验。

**Non-Goals:** 不建设独立图数据库、通用智能体编排或原生移动客户端。

## Decisions

### 页面和视觉

采用暖白背景、白色内容面板、深色正文与蓝色重点操作，按阅读顺序安排内容。主色为 `#2458ca`，深蓝强调为 `#193f96`，背景为 `#f6f5f1`，正文和辅助文字分别为 `#242c39`、`#657080`。首页搜索与筛选集中，新闻正文使用受限阅读宽度，编辑占用可用视口并固定输入区。手机将会话列表折叠，保留所有功能入口与计数。页面标题使用功能名称，说明围绕材料范围、操作或实际结果。

### 共用 Markdown

沿用 ReactMarkdown 与 GFM，集中实现标题、列表、代码、表格、图片与引用呈现。引用插件将服务端提供的编号映射为站内链接，不接受模型任意构造的目标。正文与对话使用不同宽度与字号变量，结构与样式共享。会话默认展示正文及导图实际引用的来源，其他检索材料使用可展开的列表，保留原编号和链接。正文引用识别与 Markdown 链接渲染共用同一规则。流式滚动以最新回答正文的末尾为目标，用户手动离开该阅读位置时停止跟随；重新打开会话和返回最新内容使用同一定位方式。

### 状态与工作区

会话创建更新 URL 时保持正在输出的组件，材料变更明确开始新会话，切换取消旧接收并保留服务端真实状态。业务表单提示使用共享字段组件，操作结果互不覆盖。内容查询在身份恢复或变更后刷新私人状态。日报和任务展示具体结果，错误详情与主提示分层。

### 业务页面

账号表单说明输入条件，登录后返回原目标。访问令牌仅在内存保存，会话刷新后重新取得当前身份及收藏、关注等私人状态。资讯和详情明确区分原文、摘要与译文，查询和返回保留筛选、页码与阅读位置。公共及个人日报提供日期与实际任务状态。

技能目录提供示例预览，安装及使用保留选中技能和材料；个人副本支持修改、启停及发布预览。专题支持报道、Markdown 笔记和成果管理，当前专题作为保存默认目标，重新生成保留独立成果与来源。关注和消息显示真实未读数及触发原因，分享预览与公开页使用同一快照字段。

导图提供收起和展开，关系图按连接关系分组布局，选择节点时突出关联边。窄屏和键盘通过关系列表读取相同关系及来源。分享页面以成果标题、正文和来源为主，撤销后的链接显示失效状态。

### 验证

端到端使用包含长文和多源关系的可控材料，实际浏览器检查首屏输入、正文层级、表格、引用、图谱、保存和返回路径。测试失败必须指出行为偏差，截图用于核对阅读和布局，不替代数据断言。统一检查入口在静态、类型、行为、接口和构建之后执行浏览器检查，每项只执行一次。

实际来源与模型检查覆盖正文、摘要、译文、五项技能、私人上下文、成果保存及来源引用，记录输入、实际输出和保存结果。完整运行材料写入被忽略的本地输出目录，公开说明保留可独立理解的结果及待处理项。

### 输入与失败反馈
共享字段组件使用中文说明必填、长度及格式问题，服务器字段错误显示在对应输入旁；修改输入后清除旧提示。错误摘要直接说明原因，登录与注册页面使用各自表单状态。普通输入和认证错误不展示排查编号；服务故障可展开请求标识。会话的失败原因在刷新后继续显示，重试后更新对应消息。

### 页面与组件组织

路由与应用布局负责页面装配，登录、设置及各业务页面按职责独立维护。资讯、详情、事件、热点、收藏与消息有清楚的页面入口；阅读工作区与成果展示组件由使用它们的页面复用。共享表单、反馈、Markdown 与引用、任务状态和可视化按职责组织，使用现有 API、会话和类型。

样式按基础、布局、共享内容和业务区域组织，保留既有选择器、覆盖顺序、配色与响应式行为。E2E 按使用流程分组，公共操作集中复用；目录调整保持全部现有页面、文案、角标、状态反馈、来源跳转和操作能力。

## Risks / Trade-offs

以真实长文、长标题、空内容及失败结果检查布局和交互。模型提取的数据只有通过结构与来源校验才展示为有效结果，所有私人对象继续验证所属账号。

## Migration Plan

复用已有 API、SSE、身份与数据模型，保持新闻及私人对象标识。构建静态资源并随 API 提供，在公开阅读、个人编辑、技能、专题和分享入口核对浏览器行为、刷新持久性及相邻接口，更新使用与运行文档。
