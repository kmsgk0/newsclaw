# Design

使用隔离 PostgreSQL、Redis、真实 Fastify API、合成账号和新闻；上游为本地替身。测试容器限制 CPU 和内存，不开放对外端口。k6 分别测量提交、已提交任务的查询、非语义新闻检索，参数通过环境变量提供。提交只衡量任务接收，不把尚未执行的任务视作完成。基线和改进版使用相同种子、资源上限、脚本、并发及持续时间；生成独立操作 ID。每轮保存机器可读汇总和环境信息，说明误差与容量边界。

优化前检查执行计划与耗时；仅在能保证权限及结果语义的前提下调整查询或并发。针对空结果、分页和过滤回归。不得用无依据的数字声称达到饱和或改善。

为数据库连接池提供按进程配置的 `DB_POOL_MAX`，默认保持 12，验证范围为 1 至 100。资源受限环境可按实测选择 4；应用、迁移、种子和测试连接均显式传入配置。多进程实例的连接总数需按数据库容量规划，不能把一台测试机器的值当作通用默认值。
