# Proposal

## Why

首次检查发现三个问题：模型结果校验失败后已返回的用量没有保存，OpenAPI 生成无法处理未声明 schema 的路由，个人日报将报道中的人事消息扩写为没有材料支持的技术计划。需要修复这些行为，并保留可重放的检查和处理结果。

## What Changes

- 在模型结果校验及编辑失败处理之间传递已取得的用量，保持失败状态与安全错误信息。
- 修复共享 OpenAPI 转换，使接口定义与文档页面可正常访问，保留公开与受保护接口的权限说明。
- 明确个人日报中新闻事实、兴趣关联与待确认信息的表达，使用固定材料验证内容质量。
- 将接口文档检查加入现有测试，沿用 SEC-07 自动用量检查，保存修复对照和独立评审记录并同步当前文档入口。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `runtime-operations`：失败调用用量保存及接口文档可用性。
- `personal-editor`：个人日报的事实与兴趣分析依据。

## Impact

影响模型适配器、编辑失败处理、OpenAPI 转换、个人日报生成约束，以及相关测试、评测和文档。沿用现有存储、权限、任务及验收入口，无需新增服务或数据库迁移。
