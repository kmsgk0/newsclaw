# Proposal

## Why

让读者通过个人编辑围绕新闻材料连续提问，并使用可管理的兴趣、记忆、日报与手记接续阅读活动。

## What Changes

- 实现编辑设置、新闻与事件及本人收藏材料检索，使用 MCP 复用服务和账号权限。
- 提供私人会话、连续问答、SSE 输出、失败重试、停止及进程中断恢复。
- 实现个人日报、长期记忆及增量手记，接入同一后台任务运行模块。
- 完成对应 API、文档和隔离检查，验证引用、事务、重复活动、错误及跨账号访问。

## Capabilities

### New Capabilities

- `personal-editor`: 编辑设置、材料检索、会话及个人日报、记忆和手记 API。

### Modified Capabilities

- `account-access`: 编辑相关私人对象及 MCP 的账号归属。
- `runtime-operations`: 个人日报、手记处理器、SSE 错误及工具调用追踪。

## Impact

增加编辑、会话、记忆和个性化处理模块及 MCP 适配器，扩展任务处理器、模型调用和接口文档。新闻、事件和收藏继续由现有服务提供。
