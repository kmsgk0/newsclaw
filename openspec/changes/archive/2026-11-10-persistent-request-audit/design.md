# Design

所有 API 请求完成后以参数化 SQL 写入独立审计表，保存服务生成的请求 ID、时间、已认证主体 ID、固定路由模板、方法、状态、经过 UUID 校验的对象 ID 和耗时。匿名主体用空值表示；不存原始 URL、正文、查询参数、token、用户名或模型输入。响应后写入失败时只记录固定错误标识，避免泄露错误细节；由于写入发生在响应之后，不能承诺审计与业务原子提交。

只开放管理员 GET 查询，限制每页最多 100 条，支持请求 ID 精确查询及倒序分页；普通用户和匿名用户不得查询。查询自身也产生审计记录。通过真实 HTTP、数据库和两类身份检查持久化、拒绝结果及敏感输入不出现；日志或数据库均不可记录查询明文。

技能调用另存 `skill_audit`：在回答最终状态的同一数据库事务中写入七类字段和请求 ID，失败调用也记录；仅使用受限格式的标识与内部错误码，数字用量无效时存空。管理员接口支持主体、技能、起止时间的组合筛选和分页，并对技能和主体筛选设置时间索引。进程崩溃导致无法完成最终事务的尝试不保证生成记录，既有启动恢复另行处理；历史记录不追填。
