# Proposal

## Why

读者需要控制自动生成的频率和消耗，快速了解专题的新报道，并把阅读成果带出平台。回答与引用还需要可修改的反馈入口，帮助识别阅读效果和来源问题。

## What Changes

- 新增本人自动生成设置、每日自动调用上限、后台生成用量及额度耗尽后的暂停。
- 新增按上次已读时间组织的专题进展，按事件集中展示已有摘要和来源。
- 新增单份已保存成果的 Markdown 下载，保留导图层级、来源和生成时间。
- 新增本人回答及引用反馈，以及不包含私人正文的管理员聚合统计。
- 每项功能单独提交，补充权限、失败、并发和浏览器验证。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `personal-editor`：自动生成策略、调用次数及用量、回答与引用反馈。
- `topics-and-insights`：专题新增进展和 Markdown 成果导出。

## Impact

涉及编辑与专题接口、后台调度、模型错误类型、数据库迁移、编辑设置、专题和聊天界面。不新增依赖；测试使用隔离数据库、队列及模型替身。
