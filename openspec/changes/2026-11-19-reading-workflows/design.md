# Design

## Context

沿用公共新闻、私人编辑与专题的数据边界，任务已有固定处理器和执行标识，成果已有来源快照。本轮按 proposal 补全四条阅读操作。

## Goals / Non-Goals

用户能独立完成设置、跟进、导出和反馈。自动额度按实际发起的生成尝试计次，token 为模型返回的后台生成用量统计，不估算费用或承诺全站账单。

## Decisions

- 新账号及现有账号默认手动生成。用户选择每日定时或内容更新模式，设置 Shanghai 业务时区的开始小时和每日自动调用次数，默认 3 次、范围 1–20。
- 每个后台生成执行标识记录一条用量记录。账号设置行锁保护每日次数预留，重试同样计次；模型调用前预留，失败不返还，未知用量保留为空。手动生成保留可用且单独统计。
- 每日模式每种任务成功后当日不再自动生成；更新模式沿用材料和活动指纹。调度前与执行前均检查设置、暂停和额度，避免关闭设置后排队任务继续消费。
- 上游明确返回额度耗尽时暂停该账号的自动生成至次日；本人可手动恢复。后台用量记录不含新闻、偏好或模型正文。
- 专题进展复用已有摘要，按事件分组，返回上次已读时间和本次截止时间；最多展示 200 篇，标明总数与截断。明确标记本批全部已读时只推进至该截止时间，后续新增仍未读。
- 单份成果下载为 UTF-8 Markdown，最大 1 MiB，来源最多沿用已有 100 篇上限。仅包含选定成果、导图、保存时间与公共来源，不包含专题笔记、会话、记忆或凭据。
- 每条已完成回答保存一份本人反馈，可修改或删除；引用问题必须选择当前回答的真实来源。管理员只读取类别计数及公开报道的聚合，不读取私人正文或反馈备注。

## Risks / Trade-offs

- 并发调度或任务重试可能重复消费 → 执行标识唯一约束、账号行锁及执行前复核。
- 上游可能不返回用量 → 已知字段分别累计，显式展示未知调用数。
- 查看期间新增报道可能被误标已读 → 使用服务端截止时间，已读游标不回退。
- 导出和反馈涉及私人内容 → 每个入口检查账号归属，跨账号与不存在统一返回 404。

## Migration Plan

新增自动生成设置与用量表、专题时间索引及反馈表；迁移回填手动模式，不触发模型调用。部署前备份，按既有迁移入口执行。功能与迁移一同交付，通过针对性测试及完整验收后同步规格和归档。
