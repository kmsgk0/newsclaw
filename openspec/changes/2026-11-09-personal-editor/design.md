# Design

## Context

账号已有唯一编辑记录，新闻库提供公共报道、事件和本人收藏。个人编辑通过 API 接收明确材料与问题，连续保存私人对话和阅读上下文。

## Goals / Non-Goals

**Goals:** 设置、材料、会话和生成结果可持久使用，引用可追溯，失败能够恢复。

**Non-Goals:** 不引入通用工作流或可执行用户代码。

## Decisions

### 编辑与材料

编辑设置保存名字、头像、解读风格和自然语言兴趣，明确设置优先于自动推断。编辑使用 MCP 读取公共新闻、事件或本人的收藏，工具复用业务服务和服务端身份。材料范围随会话保存，回复引用映射到真实报道。

系统消息定义回答约定，新闻材料作为外部证据随问题传入。回复直接回答问题，日期只关联材料明确说明的事件，性能判断保留测试条件与依据。材料不足和工具故障分别返回，外部内容不能改变执行权限。

### 会话与流式结果

会话提供创建、读取、重命名及删除接口，消息按所属账号和会话保存。SSE 分别发送正文、来源及终态，响应包含实际会话标识。失败回答保留原问题、错误码、安全中文原因和请求标识，重试沿用原消息标识，开始时清除旧错误，成功后保存回答及来源快照。

停止请求保留真实未完成状态。API 单实例启动时恢复中断消息，Worker 不执行该恢复动作。未完成消息不能永久阻塞新问题，空输入及越权请求在调用模型前拒绝。

### 日报、手记与记忆

业务日期采用 Asia/Shanghai。个人日报按明确兴趣和记忆选择材料，没有兴趣时使用当天新闻。读取接口返回 items、availableDates、latestDate、status 及最新任务状态；本人可以主动生成日报和整理手记。

日报与手记以 N1 等编号传入阅读材料，生成结果返回实际使用编号，宿主校验后映射到报道。手记任务标识包含成功游标及活动上界，同批重放复用任务，同日新活动形成新任务。手记合并时重映射引用，正文、记忆与处理位置在同一事务提交。手动偏好优先，删除记录约束重放旧活动时的自动记忆恢复。

### 模块与验证

会话、生成、长期记忆和后台整理按业务职责组织，MCP 与 API 复用服务及账号边界。隔离测试使用可控新闻、活动和模型响应，核对设置、引用、持续会话、停止、失败、事务回滚及跨账号数据。模块和接口文档说明实际可用的请求及响应。

## Risks / Trade-offs

外部模型失败时保留既有成功内容及原问题。生成结构与来源先校验，事实和表述效果依据实际材料另行检查。

## Migration Plan

使用共享迁移已准备的会话、记忆和生成记录，保留账号及新闻标识。接入新处理器后，在隔离数据库核对新增、更新、删除、失败重试及重复活动。
