## MODIFIED Requirements

### Requirement: FLOW-03 对照需求验证实际结果

开发者 MUST 核对规约要求是否落实，以及实际改动是否符合规约和工程规范，并执行与改动相关的检查。文档核对内容、链接和一致性，项目报告与流水线记录指向真实可核对的提交、构建、命令和报告文件；工具及应用实现验证相应行为。检查结果说明对象、方法、预期和实际结果；失败或未执行的检查不能记为通过。

#### Scenario: 完成变更检查

- **GIVEN** 本次修改已完成
- **WHEN** 对照需求场景和实际 diff 检查交付
- **THEN** 每项改动有规约依据，相关需求有对应产物和验证结果，发现的遗漏得到补齐或修正

#### Scenario: 必要检查未通过

- **GIVEN** 必要检查无法执行，或实际结果不符合需求场景
- **WHEN** 整理验证结果
- **THEN** 记录具体原因或差异，保留相关任务未完成，后续按需求修正并补验
