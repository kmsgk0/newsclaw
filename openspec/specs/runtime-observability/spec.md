# runtime-observability Specification

## Purpose
提供低基数的技能、接口和队列指标，以及可选的采集服务、运行看板和本地告警通知，使部署者能够观察服务状态并验证告警链路。

## Requirements

### Requirement: OBS-01 低基数运行指标

系统 SHALL 在显式启用时暴露内部指标，包含按固定技能类型和结果区分的执行次数、按路由模板统计的 HTTP 延迟分布，以及业务队列深度。指标不得包含账号、请求参数、正文或凭据；默认不启用服务。

#### Scenario: 技能及接口指标

- **GIVEN** 指标服务已启用，发生成功和失败的技能执行以及 HTTP 请求。
- **WHEN** 监控服务采集指标。
- **THEN** 能按固定技能类型和结果区分次数，并通过延迟直方图计算接口 P95，不出现用户或请求输入。

#### Scenario: 队列不可用

- **GIVEN** 队列依赖不可用。
- **WHEN** 采集运行指标。
- **THEN** 指标明确标记队列不可用，不能将错误伪装为零积压；已有其他指标仍可读。

### Requirement: OBS-02 看板与告警

系统 SHALL 提供可选的监控配置，展示技能调用量、技能错误率、接口 P95 及队列深度；当规则条件满足时产生可观察告警。监控访问与凭据不得默认公开。

#### Scenario: 查看指标和告警

- **GIVEN** 已启用隔离监控服务且有可观测样本。
- **WHEN** 用户查看面板并使告警阈值持续满足。
- **THEN** 面板可查询对应样本，告警状态实际进入 firing，通知接收器记录对应告警，记录操作、值与结果。
