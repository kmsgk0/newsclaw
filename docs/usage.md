# 使用说明

NewsClaw 将公共新闻与私人阅读空间放在同一套界面中。资讯、事件、站内热点、技能介绍和有效分享页可直接浏览；收藏、编辑、专题与消息需要登录。

## 页面入口

| 入口 | 使用方式 |
| --- | --- |
| `/` | 浏览报道，按关键词、来源和领域筛选，切换全站日报并按日期回看 |
| `/news/:id` | 阅读来源内容、摘要与译文，查看原文，收藏、打开编辑面板并使用阅读技能 |
| `/events/:id` | 查看多源报道、时间线和有来源的关系图，关注事件进展 |
| `/editor` | 在会话、个人日报、编辑手记、长期记忆和编辑设置之间切换 |
| `/skills` | 查看五项技能与示例，安装个人副本，调整说明、启停并发布版本 |
| `/trends` | 阅读本站收录范围内的热点排序、统计口径与历史变化 |
| `/topics`、`/topics/:id` | 建立专题，汇集报道，记录笔记，保存与分享阅读成果 |
| `/library` | 回看收藏和最近阅读，使用技能整理收藏材料 |
| `/notifications` | 查看关注范围的新报道，标记消息已读 |
| `/login`、`/register`、`/settings` | 注册登录与修改密码，登录后回到原来的私人页面 |
| `/admin` | 管理公共信源、新闻归属、公开技能与后台任务 |
| `/shares/:token` | 只读查看主动公开的成果及其依据材料 |

## 阅读与编辑

新闻和事件详情可以打开右侧编辑面板，提问时带入当前阅读对象。手机上使用可关闭的编辑面板，输入区域保持可见。编辑输出逐步显示，正文引用可直接打开报道，来源另行列出；网络或模型失败会保留问题和已有内容，并标记本次未完成。

显式选择技能时使用已安装且启用的个人副本，也可以让编辑自动选择。导图可以展开或收起，并返回依据报道。简报、对比和导图可保存到自己的专题，保存后专题成果列表会刷新。

个人日报和手记可主动生成并按日期回看，等待、无材料、失败和可读结果分别呈现；查询到成功或最终失败时停止轮询。编辑设置中的明确兴趣用于后续问答和日报；长期记忆可以主动添加、修改与删除。

## 专题与分享

专题以关键词、领域或事件为关注范围，也可手动加入新闻。笔记保持私人，支持 Markdown 预览、修改和删除；移除的报道不会被自动匹配重新加入。成果保存生成时的正文、技能与来源，支持改名和删除。发布分享前先预览公开内容，确认后生成只读链接；撤销后原链接不可访问。

## 反馈与访问

搜索和筛选保存在 URL 中，分页可以继续查看后续结果。页面分别呈现加载、没有内容、没有匹配结果和读取失败。操作失败时保留输入，成功后更新相关内容；失败不会显示为空列表成功。

访问令牌仅存在内存，页面刷新通过 HttpOnly Cookie 恢复身份。私人页面先检查登录状态，服务端独立核对资源归属与管理权限。表单使用明确标签及说明，主要操作支持键盘，手机导航通过菜单打开。

账号表单的必填、长度和格式错误以中文显示在字段旁。认证失败直接说明凭据问题；服务故障说明受影响的检索或生成服务，并可展开请求标识。失败会话刷新后仍保留原因，重试成功后清除该条错误。

## 开发与检查

前端源代码位于 `src/web/`，页面、公共组件和样式按职责维护，视觉约定见[产品设计规范](standards/product.md#视觉与交互)。页面和关系图按需加载。关系图默认打开可读的关联组，可切换命名组、全部概览或完整关系列表。开发入口使用 `npm run dev:web`，构建使用 `npm run build`；实际 API 与 Worker 的启动方法见[README](../README.md)。

执行 `npm run test:e2e` 会启动隔离的测试 API、数据库、队列与模型替身，再以 390、768、1440 像素宽度运行浏览器用例。用例覆盖阅读筛选、账号与会话恢复、记忆、收藏、技能、流式导图、成果分享撤销、失败恢复及公共任务管理。浏览器运行结果保存在被忽略的 `playwright-report/` 和 `test-results/` 中；首次运行前使用 `npx playwright install chromium --only-shell` 准备测试浏览器。
