# 实施路线图

本页保存完整目标的任务拆分；已接入能力及其变更入口见[文档导航](../README.md#阶段与变更)。以下条目作为规划索引保留，实际完成状态由对应变更任务维护。需求详情见[产品入口](README.md)，技术关系见[总体设计](design.md)。

## 交付安排

按依赖逐项建立变更，业务 API 与网页分别维护对应范围。下表保留完整目标的工作分组，当前范围由各变更确定。

| 工作单元 | 主要内容 | 对应任务 |
| --- | --- | --- |
| 运行骨架与公共基础 | 启动、配置、数据库、健康检查、日志与测试入口 | 1.1 至 1.4 |
| 账号与访问控制 | 注册登录、会话、编辑初始化、资源归属与管理权限 | 2.1 至 2.4 |
| 异步采集与资讯阅读 | 任务接收与恢复、采集、去重、摘要翻译、新闻阅读及异步验证 | 3.1 至 3.3、4.1 至 4.3 |
| 搜索、事件与热点 | 搜索筛选、事件关联、收藏与阅读记录、热点和时间线 | 3.4 至 3.6、7.4 |
| 编辑问答与 MCP | 编辑配置、材料检索、引用、流式会话与工具查询 | 5.1 至 5.3 |
| 技能广场 | 五项内置技能、个人副本、选择执行、发布与管理 | 6.1 至 6.4 |
| 个性化阅读与跟进 | 全站与个人日报、记忆、手记、关注及提醒 | 3.7、5.4 至 5.6、7.3 |
| 专题与阅读成果 | 专题、笔记、成果保存、导图、图谱与分享撤销 | 7.1、7.2、7.5 至 7.7 |
| 集成与运行交付 | 跨功能体验、模型效果、安全自查、独立启动、发布与恢复 | 8.1 至 8.4、9.1 至 9.3 |

页面和各能力自身的检查在对应工作单元中完成，页面与集成任务继续核对整体覆盖。任务编号用于引用；实际执行顺序按本轮范围和依赖确定。

## 任务维护

以下任务保留目标行为和各自的验证方法。任务纳入具体 change 后，本页相应条目改为编号、摘要及变更链接，完成状态只在该变更的 `tasks.md` 中维护。尚未交付的任务仍作为目标保留，实际状态按对应变更维护。

文档或设计变更只跟踪相应材料和核对工作。业务实现、真实模型效果及运行验证在对应的实施变更中完成。

## 1. 运行骨架与公共合同

- 1.1 建立 TypeScript 前后端与共享业务模块，提供锁文件、配置示例、Dockerfile 和 Compose，启动 API、Worker、PostgreSQL 与 Redis，API 与 Worker 共用镜像；验证按 README 从零启动、数据库与 Redis 持久化及队列配置，缺少必需配置时启动失败。对应 OPS-01。
- 1.2 实现 `/health`、`/live` 及优雅停止，补健康和配置失败用例；验证数据库断开时就绪失败且进程仍存活，停止后不领取新任务。对应 OPS-01、OPS-05。
- 1.3 实现统一响应、错误码、输入校验、请求标识与 JSON 日志，关联操作人、对象、技能、结果、耗时及实际用量或不可得标记；验证非法请求不会写入数据，被拒请求及错误可回查且不含敏感信息，同步接口文档。对应 OPS-03、OPS-04。
- 1.4 建立独立测试数据库及模型、信源、工具、时间替身，配置检查和测试命令；验证断网仍可运行已有用例，失败用例导致非零退出，并在 README 写清命令。对应 OPS-04。

## 2. 账号与资源归属

- 2.1 实现注册、密码哈希和唯一编辑初始化；测试重复用户名、非法参数和事务失败，确认无半份账号或编辑记录，同步注册接口文档。对应 ACC-01。
- 2.2 实现登录、令牌刷新、退出及修改密码；测试错误凭据、旧会话失效和浏览器令牌位置，同步会话接口文档。对应 ACC-02。
- 2.3 实现公开入口登记和默认认证保护；测试公共新闻匿名可读，私人入口未登录时被拒并引导登录。对应 ACC-03。
- 2.4 实现共享归属与管理角色校验，供 API、MCP 和任务复用；以两个普通账号和一个管理员验证跨账号 404、功能权限 403及管理操作记录，同步权限合同。对应 ACC-04、ACC-05。

## 3. 共享新闻库

- 3.1 实现信源配置和 RSS、公开 API、网页适配；测试三类固定样本、非法地址、无权限和不可达信源，同步信源接口文档。对应 NEWS-01。
- 3.2 实现报道规范化、来源保留及去重；连续采集同一报道并加入跨来源同文报道，验证重复记录不增加且各来源仍能独立打开。对应 NEWS-01。
- 3.3 实现清洗、筛选、摘要与翻译及结果复用；验证原文与生成内容区分、摘要来源不被扩写成原文、失败只补缺失结果，同步处理状态说明。对应 NEWS-02。
- 3.4 实现事件关联与管理员修正；验证多来源保留、错误归属修正后查询一致、缺失事件明确报错，同步事件接口文档。对应 NEWS-03。
- 3.5 实现精选、领域来源筛选、关键词及向量检索；验证稳定分页、空结果、非法筛选和嵌入服务失败，同步检索接口文档。对应 NEWS-04。
- 3.6 实现收藏与阅读记录；测试重复收藏、取消、最近阅读时间及跨账号访问，确认不删除公共报道。对应 NEWS-05。
- 3.7 实现按日期的全站日报；验证历史查看、同日重跑、无内容及模型失败状态，同步日报接口文档。对应 NEWS-06。

## 4. 后台执行

- 4.1 接入固定任务的调度与执行，建立任务及待投递记录、同事务接收、Worker 投递循环、`202` 响应与只读查询，记录状态、超时、结果及错误；测试成功、依赖失败、参数冲突、私人归属和无权限管理，同步任务管理接口与运行说明。对应 OPS-02、OPS-03。
- 4.2 实现中断任务识别、重新领取及有限退避重试，保留死信与人工重放记录；模拟进程中断、消息缺失、重复投递、旧尝试迟到及数据库提交失败，确认已提交业务结果不重复、较新结果不被覆盖、旧成功内容保留。对应 OPS-02、OPS-03。
- 4.3 按[异步验证](design.md#异步验证)实测提交耗时、停止 Worker 后恢复及重复请求与投递，核对接收事务回滚、只读查询和任务观测；将用例写入 `apitest/cases/` 并接入 `make check` 完整检查，保存命令、输出、数据库断言及并发和事务记录，失败返回非零并关联版本标签。对应 OPS-02、OPS-03、OPS-04。

## 5. 专属编辑与阅读记忆

- 5.1 实现编辑名字、头像、风格和明确兴趣设置；测试保存、空名字及归属校验，后续请求能取得正确设置，同步接口文档。对应 EDITOR-01。
- 5.2 实现材料上下文、检索及 MCP 新闻和事件查询，建立服务端引用映射；测试单篇、跨新闻、材料不足、非法工具参数、越权和缺失对象。对应 EDITOR-02。
- 5.3 实现私人连续会话、SSE 文本及来源事件、恢复和错误状态；测试成功完成、模型超时、工具失败、传输中断和空问题，同步流式协议。对应 EDITOR-03。
- 5.4 实现个人日报与历史回顾；测试明确兴趣优先、无兴趣使用精选、同日更新及他人不可读，并同步日报与回顾接口。对应 EDITOR-04。
- 5.5 实现长期记忆查看、修改、删除及手动偏好优先；测试冲突自动推断和跨账号访问，确认用户操作即时影响后续读取。对应 EDITOR-05。
- 5.6 实现增量做梦整理和手记、记忆、处理位置的原子提交；测试无新活动、同批重跑、同日新活动、模型失败和提交失败，确认删除项不会从已处理批次恢复。对应 EDITOR-06。

## 6. 技能广场

- 6.1 定义五项内置技能及效果示例，支持单篇、事件、收藏集合和专题材料；逐项验证输出用途、输入范围及缺失材料失败，补技能接口文档。对应 SKILL-01。
- 6.2 实现个人副本安装、修改与启停；测试重复安装、公共模板更新、非本人副本和存储失败，确认个人与公共内容互不覆盖。对应 SKILL-02。
- 6.3 接入显式与自动技能选择，并展示本次使用情况；测试显式优先、自动至多一项、停用和依赖失败，确认没有静默替换。对应 SKILL-03。
- 6.4 实现发布、上架及下架，限制公开字段并记录管理动作；测试作者发布、管理员管理、越权及私人内容不随发布暴露，同步状态转换说明。对应 SKILL-04。

## 7. 热点、专题与成果

- 7.1 实现私人专题、自动与手动报道关联、笔记和阅读位置；测试无效范围、跨账号、已删除对象及新增内容标识，同步专题接口文档。对应 TOPIC-01。
- 7.2 实现成果保存及生成时的来源快照；测试两次生成分别保存并独立回看，旧成果不被静默覆盖。对应 TOPIC-01。
- 7.3 实现关注、取消、更新提醒及已读状态；测试同篇命中多个关注只提醒一次、同事件新报道继续提醒、取消关注和保存失败重试。对应 TOPIC-02。
- 7.4 实现站内热点日统计、趋势和事件时间线；验证排序口径、统计范围、同时间稳定排序、无数据及非法筛选，同步统计说明。对应 TOPIC-03。
- 7.5 实现思维导图的结构校验、展开收起、来源跳转及保存；测试有效树、错误结构和无效来源，失败不保存成功成果。对应 TOPIC-04。
- 7.6 实现实体关系提取、存储和事件及专题图谱查询；测试节点与边的来源、归属修正、无依据关系及数据库失败，同步图谱接口文档。对应 TOPIC-05。
- 7.7 实现成果分享预览、公开快照和撤销；以匿名及两个账号验证预览内容一致、私人内容隔离、越权失败和撤销后不可读。对应 TOPIC-06。

## 8. 页面与集成验证

- 8.1 按产品规范实现页面和共享组件，接入各组已验证接口；走查正常、加载、空、错误状态及登录返回路径，核对键盘与 390、768、1440 像素布局。对应 ACC-03、NEWS-04、EDITOR-03、SKILL-01、TOPIC-01。
- 8.2 贯通浏览、提问、使用技能、保存专题、提醒和回顾流程；运行端到端用例，核对来源一致及账号隔离，验证图谱、导图和分享入口。对应 NEWS-01 至 NEWS-06、EDITOR-01 至 EDITOR-06、SKILL-01 至 SKILL-04、TOPIC-01 至 TOPIC-06。
- 8.3 使用 [AI 评测样例](../evaluation/ai-cases.md)核验真实模型回答、引用、技能和记忆效果；逐项记录实际结果，核对工具权限和失败路径，不能以模型自述代替判断。对应 EDITOR-02、EDITOR-05、EDITOR-06、SKILL-03、TOPIC-04、TOPIC-05。
- 8.4 按[安全检查方法](../security-checks.md)登记至少 5 个受保护接口及全部相关写入入口，运行七项自查、权限与异步风险检查和问答样例；保存实际结果、日志缺口、风险记录及真实问题的修正前后证据，由另一位协作者独立复现至少两条，并走通登录、提交 `202`、查询成功及跨账号拒绝的链路。对应 ACC-02 至 ACC-05、EDITOR-02、SKILL-02、SKILL-04、TOPIC-01、OPS-02 至 OPS-04。

## 9. 发布与恢复验证

- 9.1 完善实际启动、配置、接口和测试文档，在另一独立环境从零运行；核验记录与文档步骤一致，所有业务任务和必要检查通过。对应 OPS-01、OPS-04。
- 9.2 实现版本标识、迁移、备份和恢复步骤；从当前与上一版本分别启动，在隔离数据库恢复备份并核验关键关联和权限，记录实际耗时与恢复点。对应 OPS-05。
- 9.3 完成所有需求场景对应检查后运行 `openspec validate --all --strict --no-interactive`，核对每项任务都有行为或运行证据；对应变更存在未完成项时保持活动状态。对应全部能力。
