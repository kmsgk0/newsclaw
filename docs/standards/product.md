# 产品设计规范

## 用户与页面

游客浏览公共资讯，登录用户使用专属编辑及私人阅读空间，管理员维护公共内容和运行任务。私人内容不因管理角色自动开放。

| 页面 | 路由 | 内容与动作 |
| --- | --- | --- |
| 资讯中心 | `/` | 精选、搜索、领域及来源筛选、全站日报 |
| 新闻详情 | `/news/:id` | 来源原文或可用摘要、译文、收藏、询问编辑、使用技能 |
| 事件详情 | `/events/:id` | 概况、多源报道、时间线、关系图与关注 |
| 我的编辑 | `/editor` | 会话、人设、兴趣、记忆、个人日报、编辑手记 |
| 技能广场 | `/skills` | 介绍、示例、安装、个人副本、发布管理 |
| 热点 | `/trends` | 站内热点及近期趋势 |
| 专题 | `/topics`、`/topics/:id` | 我的专题、报道、笔记、导图、图谱和保存成果 |
| 收藏与记录 | `/library` | 收藏、已读记录及继续阅读 |
| 消息 | `/notifications` | 更新提醒、已读状态及相关内容入口 |
| 账号 | `/login`、`/register`、`/settings` | 注册登录、账号设置 |
| 管理 | `/admin` | 信源、公共内容、公开技能及任务 |
| 分享 | `/shares/:token` | 主动发布的成果快照，只读 |

非法路径显示 404。未登录访问私人页面时引导登录，登录成功后返回原目标；后端仍独立验证权限。日报、手记和记忆在编辑页面内分区，新闻及事件复用同一编辑交互。

## 状态与文案

| 状态 | 展示要求 | 文案示例 |
| --- | --- | --- |
| 加载 | 显示正在执行的动作，保留已加载内容 | 正在读取报道 |
| 正常 | 显示结果、必要来源和操作 | 已保存到专题 |
| 空状态 | 解释没有内容并给适用动作 | 还没有收藏，可以从资讯中心收藏新闻 |
| 错误 | 说明失败对象及下一步，保留输入和既有结果 | 本次回答未完成，请重试；之前的消息已保留 |

统一使用“新闻、事件、编辑、技能、专题、日报、编辑手记、长期记忆”。新闻表示单篇报道，事件汇集多篇报道；编辑手记表示私人阅读回顾，不能充当新闻来源。摘要、译文及模型整理结果与来源正文清楚区分。

字段失焦时提示问题，提交时完整校验；错误贴近字段显示。提交期间抑制重复点击，失败保留已填写内容。导图或图谱无法生成时显示失败状态，不用空白图冒充成功。

## 视觉与交互

间距使用 4、8、12、16、24、32 像素刻度；正文字号使用 14、16 像素，标题使用 20、24、32 像素。颜色与组件集中定义，成功、提示和错误使用一致的语义色，并配文字反馈。标准组件覆盖按钮、输入框、列表、卡片、对话框、提示和加载状态。

布局在 768 像素以下采用单列阅读，辅助编辑面板按需打开；768 像素以上允许阅读与编辑并列。检查 390、768、1440 像素宽度下的主流程，正文和操作不得横向溢出。键盘可到达主要控件，表单标签关联输入，焦点清晰可见。侧边导航不用选中竖条或扁椭圆浅蓝胶囊。

## 业务状态

技能发布使用草稿、已发布、已下架状态。作者可编辑草稿并发布，作者或管理员可下架公开内容，重新发布需通过权限和内容校验。安装后的个人副本独立启停，公共模板修改不覆盖副本。

后台任务使用等待、执行中、成功、失败状态，状态变化由服务端执行。分享具有有效和已撤销状态，撤销后只读链接不可用。并发操作发生冲突时返回当前状态，避免静默覆盖另一方已完成的操作。

如新增数据导入导出，必须在对应需求中先明确格式、数量与大小上限。导入先校验并预览，用户确认后整批生效，失败显示行号和原因；导出仅包含授权范围并应用敏感字段规则。该约定不要求新增通用导入中心。

## 检查

对照路由及需求走查正常、空数据、加载失败和权限路径；核对表单、键盘、三个宽度及来源跳转。新增页面复用已有组件和术语。发现未列明的入口、缺失状态或不一致文案时，修改实现并同步相关页面定义。
