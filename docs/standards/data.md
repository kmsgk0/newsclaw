# 数据规范

NewsClaw 的数据关系见[技术设计](../product/design.md#2-数据关系)，查询、唯一约束和事务沿用[后端规范](backend.md)。

## 数据范围

新闻和事件等公共内容供全站使用；会话、记忆、收藏、专题及个人技能等私人内容按账号归属访问。分享只公开用户选定的成果，不能附带其他私人数据。

凭据与私人内容按[安全规范](security.md)处理，不进入公开材料或普通运行日志。字段、命名和存储方式随实际数据模型统一确定。

## 变更与删除

数据结构变化通过迁移文件随代码管理，说明对已有数据的影响，并检查迁移后的相关读写和数据关系。备份与恢复沿用[运维规范](operations.md)。

删除操作核对关联记录及实际存在的副本，处理范围符合对应业务需求：

- 取消收藏只移除当前账号的收藏关系，保留共享新闻。
- 删除记忆后不再用于个性化，重跑同批已处理活动不能恢复该记忆。
- 撤销分享后原链接不可访问，所有者仍可查看原成果。

数据保留与清理方式按实际用途确定，清理运行记录不能顺带删除业务内容。

## 检查

使用本人和其他账号分别检查读写，确认权限及数据变化符合需求。涉及迁移或删除时，核对已有数据、关联关系及应保留的内容；发现问题后修正相关实现，再回归受影响操作。
