# 后端开发规范

## 分层与接口

业务模块分为路由、服务和数据访问。路由验证身份与参数，服务处理业务规则及事务，数据访问层执行参数化查询。模型、信源和 MCP 协议集中在适配层。后台任务、API 和工具调用复用同一服务，业务层不依赖 HTTP 请求对象。

业务接口使用 `/api/v1` 前缀，资源路径采用小写复数，GET 读取、POST 创建、PATCH 修改、DELETE 删除；健康检查使用 `/health`。每个接口在 OpenAPI 中声明请求、响应、权限和失败结果。

JSON 响应统一包含 `code`、`message`、`data`、`requestId`。成功码为 `OK`，没有数据时 `data` 为 `null`；错误不携带堆栈。流式接口使用 SSE 文本、引用、工具状态、完成和错误事件，错误事件携带同样的 `code`、`message` 和 `requestId`。

| 业务码 | HTTP 状态 | 含义 |
| --- | --- | --- |
| `OK` | 200 或 201 | 操作成功 |
| `INVALID_INPUT` | 400 | 类型、范围、筛选或结构不合法 |
| `UNAUTHENTICATED` | 401 | 未登录或会话失效 |
| `FORBIDDEN` | 403 | 没有管理或功能权限 |
| `NOT_FOUND` | 404 | 资源不存在或不属于当前账号 |
| `CONFLICT` | 409 | 重复账号或业务状态冲突 |
| `DEPENDENCY_UNAVAILABLE` | 503 | 数据库、模型、信源或工具不可用 |
| `INTERNAL_ERROR` | 500 | 未预期故障，提供请求标识供排查 |

新错误码在此表登记后使用。SSE 响应开始前使用 HTTP 错误响应，开始后以错误事件结束本次输出，不能再发送成功完成事件。

## 输入与数据访问

接口边界按 schema 验证类型、必填字段、长度、范围与枚举。数值限制以相关需求为准；分页默认每页 20 条，最大 100 条，超范围请求返回 `INVALID_INPUT`。筛选和排序字段使用明确清单，非法筛选不能当作未传条件。

列表排序最后追加唯一标识，翻页保持确定顺序。数据库查询只在数据访问层出现，服务层通过明确方法访问数据。私人资源按账号约束查询；管理员操作公共内容时另验角色。

新闻以信源与规范化 URL 标识报道，不以正文哈希合并不同来源。相同正文可以共享处理结果，报道来源、链接和发布时间仍独立保留。

## 事务与重复执行

事务只包含必要数据库操作，不夹带模型请求、外部 HTTP 调用或长耗时计算。外部调用完成后，用短事务验证当前状态并保存结果。手记、记忆更新和成功处理位置在同一事务提交。

| 操作 | 重复执行合同 |
| --- | --- |
| 采集 | 同一信源与规范化 URL 更新同一报道 |
| 收藏 | 同一账号与报道只保存一次收藏 |
| 技能安装 | 同一账号重复安装同一模板返回已有个人副本，不重置个人修改 |
| 日报、手记 | 同一账号与业务日期只保留一份对应记录，更新成功后才替换结果 |
| 提醒 | 同一账号对同一新增报道只收一条提醒 |
| 分享撤销 | 已撤销的分享再次撤销仍保持不可访问 |

对应唯一约束放在数据库中。其他写接口在 OpenAPI 中说明是否幂等。状态变更使用条件更新，发现过期状态时返回冲突；失败事务不留下半份业务结果。

## 配置与外部调用

地址、密钥和运行开关从环境读取，必需配置缺失则启动失败。按用途区分对话模型与嵌入模型配置。外部调用设定超时，工具循环和任务重试有明确上限，不能无限执行。

MCP 工具参数经过 schema 校验，身份与资源权限由宿主确定。工具仅调用既有服务，不通过参数接受任意 SQL、文件路径或目标 URL。工具错误保持可识别，已有成功内容继续可读。

## 检查

核对 OpenAPI 与实际路由，验证非法输入、重复执行、分页稳定性、跨账号访问及依赖失败。审查数据访问位置和事务边界；删除一个必需配置时启动应失败。错误码或响应形状不一致时修复共享封装，避免逐接口添加不同写法。
