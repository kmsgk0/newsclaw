# 安全开发规范

## 访问与会话

新增接口默认要求登录，公开入口显式登记。公共资讯、事件、热点、技能介绍及有效分享可匿名读取；私人收藏、会话、记忆、日报、手记、消息和专题始终验证所属账号。

跨账号资源与不存在资源统一返回 404。普通用户访问管理操作返回 403。MCP、后台执行和页面接口使用相同的归属合同，客户端提交的账号标识不能改变执行身份。管理身份不提供读取其他用户私人会话和记忆的入口。

密码采用成熟的加盐哈希。访问令牌只放内存，刷新令牌放 HttpOnly、Secure、SameSite=Strict Cookie 并支持轮换；不把令牌放入 URL、日志或浏览器本地存储。退出使对应会话失效，修改密码使既有会话失效。开发环境使用安全上下文或明确的本地开发配置，部署配置必须启用安全 Cookie。

认证浏览器写请求同时检查来源和绑定会话的一次性 CSRF token；使用刷新 Cookie 的会话刷新也须提供 token。服务端只保存 token 摘要并原子消费，过期和重放被拒，退出时随会话清理。浏览器并发写入各取得独立 token；无 Origin 的 Bearer 客户端不以 Cookie 作为认证依据。

## 输入、内容和工具

按白名单验证类型、长度、范围与枚举，查询使用参数绑定。新闻、技能说明及工具结果按外部数据处理，不能自行改变系统权限或工具集合。引用只能指向本次材料中的有效报道。

富文本以受限渲染方式呈现，模型文本不作为任意 HTML、脚本或命令执行。导图与图谱校验结构和来源。技能仅包含说明和配置，不运行用户提供的代码。

采集目标来自管理员维护的信源，模型与 MCP 地址来自服务端配置。外部请求与跳转都检查目标，不能通过正文或用户参数访问任意内网服务。私人附件如被引入，读取必须关联业务对象并验证权限，不能只凭文件标识下载。

## 机密与依赖

密钥通过服务端环境注入，`.env` 不进入 Git；`.env.example` 只含键名和占位值。机密不进入镜像层、前端、日志、错误、问题单和截图。日志只记录定位故障需要的标识及结果，不记录完整私人对话。

发现泄露时，由部署维护者立即撤销旧密钥，替换运行配置并重新验证服务；历史处理另按实际暴露范围决定，删除文件不等于撤销密钥。

新增依赖说明用途与许可证，锁文件入库。依赖更新和发布前执行漏洞检查，实际运行路径中的高危问题阻断发布；确认无影响的项记录适用版本及依据。

模型处理与数据管理的相关约定见 [AI 应用规范](ai.md)和[数据规范](data.md)。

## 检查

每个私人资源配一条跨账号场景，每个管理能力配一条低权限场景。检查失效会话、非法参数、出站目标、输出渲染和引用归属。仓库与构建产物检查机密，日志检查敏感内容。移除一处授权判断时，对应权限用例必须失败；发现问题后修复共享权限入口并回归受影响路径。

检查时对照相关场景和权限改动，说明测试身份、操作、预期及实际结果，拒绝写入时核对数据未被修改。扫描和依赖审计注明检查范围及发现，未检查的部分如实说明；证据保存遵守[测试规范](testing.md)。

身份、接口清单、七项检查及权限、并发、事务的具体方法见[安全检查方法](../verification/security.md)，实际基线和审查记录见[报告索引](../../reports/README.md)。

## 请求审计查询

API 请求结束后，服务将请求 ID、时间、已认证主体 ID、方法、路由模板、状态、有效 UUID 对象 ID 和耗时写入 `request_audit`。记录不包含请求正文、查询字符串、原始路径参数、凭据或模型输入。匿名请求的主体为空。管理员可通过 `GET /api/v1/admin/audit` 倒序读取，使用 `requestId`、`actorId`、`status`、`from` 和 `to` 筛选，`limit` 为 1–100，`offset` 为 0–10000；匿名和普通账号无权读取。

写入发生在响应结束后，与业务事务不具备原子性；数据库不可用时，服务输出不含错误详情的 `audit/write-failed` 日志。审计表当前没有自动清理策略，应由部署方制定保留周期并控制数据库与备份访问，不能将其视为防篡改日志。

技能调用完成或失败时，`skill_audit` 在保存回答最终状态的同一事务中记录操作人、时间、`skill.invoke`、会话及消息标识、结果和错误码、技能标识、可得的输入与输出 token 数、耗时及请求 ID；不保存问题或回答正文。未提供或无效的用量记为 null。管理员可通过 `GET /api/v1/admin/skill-audit` 按 `actorId`、`skillId`、`requestId`、`from` 和 `to` 筛选，并使用 `limit`、`offset` 分页；普通用户和匿名用户不能读取。技能请求的响应头 `X-Request-Id` 可用于关联查询。进程在最终事务前崩溃时无法保证该次调用生成记录，历史记录也不会自动补齐；若审计写入持续失败，回答无法保存最终状态，可能保持 pending，需在恢复数据库后通过服务启动恢复流程处理。
