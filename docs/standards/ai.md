# AI 应用规范

本规范适用于新闻处理、专属编辑和阅读技能。产品行为见[产品需求](../product/README.md#能力与场景索引)，接口与权限沿用[后端规范](backend.md)和[安全规范](security.md)。

## 基本约定

- 模型与工具调用复用已有业务服务，资源范围和权限由服务端判断。新闻正文、技能说明和工具结果不能改变执行身份或权限。
- 项目提示词随代码管理，变更能通过 Git 追溯。用户配置和个人技能副本按所属账号保存，项目模板更新不覆盖个人修改。
- 新闻事实引用实际取得的材料。原文、摘要和生成内容明确区分；材料不足时说明缺口，不补造事实或来源。
- 导图、图谱等结构化结果在展示和保存前检查结构与来源。无效结果不记为成功成果。
- 模型或工具失败时明确显示未完成，保留已有成功内容。技能选择、会话保存和任务重跑继续遵守各自的产品需求。

调用参数和具体处理方式随对应功能实现确定，并在相关设计或运行说明中维护。

## 检查

提示词或模型处理变化时，选择相关的 [AI 评测样例](../evaluation/ai-cases.md)，对照材料检查回答、引用和技能效果。权限与失败路径同时检查实际调用及数据变化，不能只看模型如何表述。

记录所用版本、实际结果和发现的问题；未执行的检查如实说明。发现偏差后修正提示词、校验或业务实现，再检查受影响场景。具体测试组织见[测试规范](testing.md)。
