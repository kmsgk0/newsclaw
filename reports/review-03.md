# 账号权限与手机端日报

2026-11-22，在 `ec24c60` 的干净源码副本上运行接口回归和 Playwright。环境为 macOS、Docker Compose、PostgreSQL 17、Redis 7.4 和真实 Worker。两个读者账号分别使用独立浏览器会话，新闻与模型响应由本地 HTTP 服务提供。

## 接口回归

| 检查项 | 判据与实测结果 |
| --- | --- |
| SEC-01/02 账号隔离 | 九个私人入口对匿名请求均返回 401，公开新闻返回 200。跨账号读写私人记忆、专题均返回 404。 |
| SEC-12 会话令牌 | 携带有效令牌可写入；缺少令牌返回 403，数据未变。重放、过期、跨会话、并发和刷新断言均通过。 |
| SEC-14 回答校验 | 模型替身返回无效引用，客户端收到错误事件，没有正文事件；数据库中回答状态为失败，正文为空。 |

三个用例分别运行，退出码均为 0。

```sh
node --import tsx --test apitest/cases/security.test.ts
node --import tsx --test apitest/cases/csrf.test.ts
node --import tsx --test --test-name-pattern=SEC-14 tests/editor/editor-api.test.ts
```

## 手机端日报

使用 Chromium 158 的 390 × 844 触屏视口。测试信源提供一篇当日新闻。提交前暂停 Worker，在页面轮询到待处理后启动；模型替身延迟 6.5 秒返回日报。

| 操作 | 实际结果 |
| --- | --- |
| 账号 A 打开「我的编辑」并登录 | 登录返回 200，页面显示个人编辑入口。 |
| 打开「个人日报」，点击「生成今天的日报」 | 接口返回 202、任务标识和查询地址。 |
| 等待页面轮询 | 同一任务依次返回 `pending`、`running`、`succeeded`，执行一次。页面显示「处理完成」、日报正文和指向新闻的引用。 |
| 账号 B 登录并查询同一任务 | 返回 404 和 `NOT_FOUND`，数据为空。按任务标识回查请求审计，A 的查询为 200，B 的查询为 404。 |
