# 检查报告

正式报告说明检查对象、版本、方法、实际结果与发现；详细输出和必要截图按日期与主题归组，通过正文链接查阅。同一正式报告直接更新，历史由 Git 保存。

| 报告 | 范围 |
| --- | --- |
| [安全基线](security-baseline.md) | 当前仓库文件与可达历史的密钥扫描，以及检查工具依赖审计 |
| [仓库文档与检查工具审查](review-01.md) | 文档一致性、现有 npm 检查及其实际输出 |

`review-01` 表示第一份正式审查记录，具体主题、执行方式与范围以正文为准。其他工作使用对应日期和主题目录保存材料，并在本索引登记。正式运行报告的内容与位置见[安全检查方法](../docs/security-checks.md#执行与记录)。

本机路径、连接别名和敏感内容在公开前移除或替换，处理方式写入报告。原始凭据、私人数据和临时调试日志仅本地保存，报告中的链接只指向可公开的证据。
