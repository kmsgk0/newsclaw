## 用量记录

模型适配器在读取响应后取得用量，JSON、输出结构或响应封装校验失败时通过错误对象传递。编辑失败出口将该用量写入原有消息和调用日志。导图在材料引用校验前接收用量，防止合法响应中的用量因后续引用错误丢失。没有返回或只返回部分用量时，缺失字段继续为 null，不推算数值。

复现及检查入口：

```sh
node scripts/checks/check.mjs --stage usage
node --import tsx --test tests/runtime/model.test.ts tests/editor/usage-recording.test.ts
```

修复前原用例为 1 通过、1 失败；修复后为 2 通过、0 失败。新增检查覆盖无效 JSON、输出结构、响应封装、材料引用以及缺失和部分用量，核对失败事件、实际落库值及安全错误。临时移除失败出口的用量接收后，三个相关子用例失败；恢复后通过。
